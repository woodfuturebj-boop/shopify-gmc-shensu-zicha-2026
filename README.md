### 为什么 80% 的政策页都齐全，还是被 Google 判“虚假陈述”？

3. **捆绑 / 订阅插件改乱了价格代码**：装了 Kaching Bundles、WideBundle 或 ReCharge，默认勾选多件折后价或订阅 85 折，但网页底层代码（JSON-LD）报给谷歌的还是单件原价。
